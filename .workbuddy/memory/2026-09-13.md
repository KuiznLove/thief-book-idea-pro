## 伪装素材多语言化 + 设置页"代码语言"下拉（v0.2.0）

需求：新增 Java / Vue 两套代码素材库，并在设置里加一个"选代码语言"的选项。

### 改了什么
- `DisguiseContent`：代码片段按语言分三组 `PYTHON_SNIPPETS` / `JAVA_SNIPPETS` / `VUE_SNIPPETS`，每组 8 个（数量与 `AssistantPageView.MAX_EXTRA_CARDS + 1` 对齐，保证同页不出现重复片段）。新增语言常量 `PYTHON` / `JAVA` / `VUE`、白名单 `LANGUAGES`、`DEFAULT_LANGUAGE`（Python，与老配置兼容）。
  - API 改为 `snippet(language, seed, index)` / `snippetCount(language)`；取模从 `index * 3` 改成 `+ index`（原来的系数只对长度 8 才是双射，现在对任意长度都能保证"index 不同则不重复"）。
  - Java 素材：图计算 / 训练服务风格（`.java` + `.yaml`，角标 `JAVA` / `YAML`）；Vue 素材：Vue 3 + TypeScript（`.vue` + `.ts`，角标 `VUE` / `TS`）。
- `AssistantPageView.render(...)` 增加第 5 个参数 `language`；`MainUi.setPageText` 传 `persistentState.getCodeLanguage()`。
- `PersistentState` 新增 `codeLanguage`（默认取 `DisguiseContent.DEFAULT_LANGUAGE`，缺失/非法值回退 Python）；`Setting.isModified/apply` 同步。
- `SettingUi`：Style 面板新增 "Code language" 下拉——用**运行时 `FormLayout.appendRow` 追加**（同 TTS 热键的做法，不动 `.form` / `$$$setupUI$$$`），落在 (2,15) / (4,15)。
- `.workbuddy/tools/SettingPreview.java`（新增）：实例化 `SettingUi` 并打印每个控件占用的 FormLayout 单元格与当前值，用来验证运行时追加的控件没有和既有控件抢格、`innit()` 回填是否生效。

### 环境坑（新发现）
- 离线跑 `SettingPreview`（会构造 `com.intellij.ui.FontComboBox`）需要额外加 `--add-opens=java.desktop/javax.swing=ALL-UNNAMED`，否则 `GraphicsUtil` 静态初始化抛 `InaccessibleObjectException: module java.desktop does not "opens javax.swing" to unnamed module`。完整参数已写进 AGENTS.md。

## 新增单行 shell 代码块 + 设置开关（v0.3.0）

需求：再加一个独立的 shell 代码块，只占一行，插在自然段中间把段落切开；设置里加开关。

### 设计
- `DisguiseContent.SHELL_COMMANDS`（10 条，只存命令本身、不含 `$`）+ `shellCommand(seed, index)`：**第四类素材，不随 `LANGUAGES` 切换**，`$` 提示符由渲染层用 `AssistantTheme.SHELL_PROMPT` 画。
- `AssistantPageView` 三个新成员：`shellSlots()`（挑候选段落）、`splitPoint()`（找切点）、`shellLine()`（渲染单行块）。`render(...)` 增加第 6 个参数 `shellEnabled`。
  - 切点必须落在 **35%~65% 区间内的句末标点**（`。！？；…`）之后；找不到就整段不插，**绝不在句子中间硬断**。

- `AssistantTheme` 新增 `SHELL_BG` / `SHELL_BORDER` / `SHELL_PROMPT`（JBColor 配对）。
- `PersistentState.shellBlockEnabled`：**"非 0 即开"**，这样老配置升级上来默认就带这个效果（`isShellBlockEnabled()` 返回 `!"0".equals(v)`，null → true）。

### 阈值标定（踩过一次坑）

## shell 块补上完整卡片头部 + 卡片头部窄宽度降级（v0.3.1）

需求（用户发来一张带完整头部的 diff 卡片截图）："shell 代码块把这个也加上"，并确认头部取"整套头部，把 Apply 改成 Run"、角标取 "SH + 脚本名"。

### 改了什么
- `DisguiseContent`：shell 素材从 `SHELL_COMMANDS`（`String[]`，只有命令）改成 `SHELL_SCRIPTS`（`ShellScript[]`，文件名 + 命令配对，10 个，如 `scripts/build.sh` + `./gradlew build -x test`），取用改走 `shellScript(seed, index)`；新增 `TOAST_RUNNING`（"已在终端运行"）。旧的 `SHELL_COMMANDS` / `shellCommand()` 已删除。
- `AssistantIcons.play(size, color)`：实心播放三角，给 shell 的 Run 按钮用（与 diff 的 Apply 对勾区分）。
- `AssistantPageView`：
  - `cardToolbar(copyText, primaryLabel, primaryIcon, primaryTooltip, primaryToast)` 抽成通用方法——diff 卡片传 "Apply" + check + "应用到工作区" + `TOAST_APPLIED`，shell 传 "Run" + play + "在终端运行" + `TOAST_RUNNING`。
  - `shellLine()` → `shellBlock(script, index)`：头部与 diff 卡片同构（`fileBadge("SH", …)` + `scripts/xxx.sh` + 复制/导出/刷新 + Run），正文仍只有一行 `$ 命令`（`shellBody()`）。
- `AssistantTheme`：删 `SHELL_BG` / `SHELL_BORDER`，shell 块直接复用 diff 卡片的 `CARD_BG` / `CARD_BORDER`（保证"同一类卡片"的观感）。
- 版本 0.3.0 → **0.3.1**（`build.gradle` + `plugin.xml` + change-notes + README 的 V0.3.1 节）。

### 顺手修掉的既有 bug：窄宽度下卡片头部叠字
- 放大核对时发现 **diff 卡片在极窄宽度下同样会叠字**（不是 shell 单独的问题）。根因：`FileNameLabel.fitTo(available)` 在 `available <= 0` 时直接 `return`，文件名原样留着，而头部是 BorderLayout、两侧会直接重叠。
- 修法是在 `layoutCardHeader()` 做三级降级（diff / shell 共用）：
  1. 收窄文件名（丢目录前缀 → 尾部省略号）；`available <= 0` 时清空文本；
  2. 收起 `CardToolbar.minor`（复制/导出/刷新三个次要图标），只留主按钮；
  3. 连主按钮都放不下（工具窗口拖到极窄）就整条工具栏 `setVisible(false)`。
- **踩坑**：第一版把"完整工具栏宽度"写成 `toolbar.getPreferredSize().width`，修完仍然叠字——`FlowLayout.getPreferredSize()` 会**跳过不可见组件**，收起 minor 后它就不再是完整宽度，判定因此来回翻转（收起 → 变窄 → 判为放得下 → 又展开）。改成在 `CardToolbar` 构造时把 `fullWidth` / `primaryWidth` 算死缓存才稳定。
- 触发条件很窄（工具窗口 ~350px + 左侧"历史记录"展开，卡片只剩 ~110px），正常宽度不受影响。

### 验证
- 新增 `.workbuddy/tools/PngCrop.java`（之前是临时写在 `.workbuddy/tmp/` 的 `Crop.java`）：裁一块放大核对局部排版。**缩略图根本看不清文件名有没有被工具栏压住，必须放大看**——这次两个叠字 bug 都是靠它发现的。
- `UiPreview` 新增第 8 张 `preview-narrow.png`（固定 400px + 侧栏展开），让窄宽度降级每次预览都被覆盖，不依赖手输参数。
- 宽度三档实测：560（全显示：SH + `scripts/dev.sh` + 4 个按钮）/ 400（中间档：文件名收窄成 `dev.sh`，只剩 Run）/ 340（卡片 ~114px：工具栏整条隐藏，只剩 SH + 文件名），三档都不叠字；正常宽度下 diff 卡片与之前逐像素一致（分布统计 y 值不变）。
- `zipcheck.js`：新增 `SHELL_SCRIPTS` / `scripts/build.sh` / `已在终端运行` / `layoutCardHeader` / `CardToolbar` 守卫，以及 `SHELL_COMMANDS` / `shellLine` "应消失"检查。
  - 顺带修了脚本自身的两个坑：class 常量池里的字符串是 **modified UTF-8**，中文 needle 必须先 `Buffer.from(n,'utf8').toString('latin1')` 才能比对（原先直接 `includes(中文)` 永远 MISS，害我以为常量没打进去）；删掉拿 `model.eval()` 判断"Java 素材是否回退"的误报项（那是 Python 组的素材，从来没换过）。
- `buildPlugin` 出包 `thief-book-idea-0.3.1.zip`，zipcheck 全 OK。
