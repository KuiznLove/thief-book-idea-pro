### 独立验证结论（都实跑过，不是只看自测）
- **IO 算法零改动**：`readLines` / `appendLine` / `detectCharset` 与重构前**逐字符相同**；`countLine`→`countLines` 只多了加锁、try-with-resources 与"不再吞异常返回 0"。
- **翻页算法等价**：`turnNext`/`turnBack`/`jumpTo` 与旧 `nextPage`/`previousPage`/`jumpToPage` 的算法一致，守卫留在 `MainUi`。
- **配置兼容性 20/20 一致**：比对 481ca58 手写版写出的属性名 vs 新版 `@Attribute`，集合完全相同（除 `<book>` 子元素的 path/line）；老配置可原样读取。
- `StateCheck` / `PagerCheck` 实跑 **ALL PASS**；23 个源文件全量编译零错误；`build/distributions/thief-book-idea-0.3.3.zip` 内含 `book/BookPager.class` 等。

### 发现的隐患（已停在第 1 条：需用户决定是否修）
1. **`BookPager.turnBack()` 无下限保护 → 越界后污染 `seekDictionary[0]`，导致后续跳页整体错位**：
   首页连续 turnBack 两次 → `currentPage=-10`（`displayPage()` 会显示页号 -1），之后 `jumpTo(10)` 返回 L21 而不是 L11（错 10 行）。
   当前 UI 守卫 `currentLine()/lineCount <= 1` 拦住了用户路径，所以线上碰不到；**旧实现同样存在**（不是本次回归）。
2. `runIoAsync` 的失败提示把 `e.getMessage()` 直接展示 → IOException 常含绝对路径 / 英文系统提示，伪装会露馅。
3. 老板键 `bossKeyDown` 的复位依赖 `instances` 非空：按下期间项目被关或热键被改 → 标志卡在 true，老板键失效到重启 IDE。
4. （P3）全局 AWT 监听器 lambda 无法注销；切书时旧 epub 临时资源仍靠 `deleteOnExit`；空 `bookPath` 时 `refresh()` 每次都重建引擎。

### 工具与环境
- 新增 `.workbuddy/tools/PagerEdgeCheck.java`：补 `PagerCheck` 没覆盖的三种边界（越界上一页 / 越界后 jumpTo 定位 / CRLF），当前有 **2 条 FAIL，正是上面第 1 条隐患**。
- 跑 `PagerCheck` / `StateCheck` 需要 platform lib + epublib + jsoup：用 `node` 扫 `.gradle/caches/modules-2/files-2.1` 拼 classpath，再配 `build/classes/java/main`（或自己 javac 出来的临时目录）。
- ⚠️ **踩坑**：在本机 Git Bash 里 `git show <rev>^:<path>` 的 `^` 会被吞掉（取到的是 `rev` 本身），会得出"重构前就已经是 XmlSerializer"这种错误结论。要先用 `git rev-parse <rev>^` 解析出哈希再取文件。
