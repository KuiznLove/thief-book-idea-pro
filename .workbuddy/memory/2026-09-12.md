# 2026-09-12

## 伪装改造：阅读窗口 → AI 编码助手面板（v0.1.7）

需求：把 IDEA 摸鱼阅读插件的外观改成 AI 编码助手，"正文"当作助手的回复，中间插入伪装代码块，底部加输入框（参考 Trae 的截图）。

### 做了什么
- 新增 `com.thief.idea.disguise.DisguiseContent`：开场白/小标题/结尾话术/伪造 diff 代码片段/模型名/TOAST 文案，按 `bookFile + currentPage` 派生的 seed 确定性选取（同页刷新不变，翻页换一批）。
- 新增 `com.thief.idea.ui`：
  - `AssistantTheme`：JBColor 亮/暗配对配色 + `GlyphButton`/`RoundedPanel`（圆角裁剪子组件）+ `stretch()`；
  - `AssistantIcons`：Graphics2D 手绘矢量图标（品牌星、箭头、复制、下载、刷新、勾、喇叭、图片、文件角标）；
  - `AssistantPageView`：一页正文 → 开场白 + diff 卡片 + 段落（按比例插入小标题 + 第二个卡片）+ 结尾话术；正文里的英文/数字渲染成灰底行内代码块；实现 `Scrollable#getScrollableTracksViewportWidth`，内嵌 `ParagraphPane` 自算换行高度；
  - `ChatInputBar`：伪装的底部输入区（占位提示、@ / # / 图片、模型选择、绿色发送按钮），实际用于翻页/跳页（回车=下一页、↑↓=翻页、数字=跳页、/next /prev /play /stop /boss）。
- `MainUi` 重写 UI 部分（读文件的 IO 逻辑原样保留）：顶部品牌栏（可右键重命名）、页码指示、上一条/下一条/喇叭按钮、5x5 隐形老板键、老板键改为收起对话区显示假 Terminal、热键注册到 rootPanel、字体按 type+size 缓存。
- 工具窗口 id 改为 `ai-assistant`（stripe 名来自 `messages/AssistantBundle.properties`），设置页改 `AI Assistant Config`，action 改 `Show CodePilot`，插件名/描述/图标（`icons/assistant.png` + `@2x`，由 IconGen 生成）同步更换。
- 「每页行数」下拉从 1~3 扩到 1~30（`SettingUi.form` 与生成的 `SettingUi.java` 两处手工同步），默认值 8。

### 验证方式（重要，可复用）
- 本机 Git Bash 没有 coreutils，`./gradlew` 跑不了 → 用 `java -classpath gradle/wrapper/gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain <task>`；JDK17 在 `E:/Java/jdk-17`（gradle.properties 原来的 `D:/soft/...` 已改）。
- 离线渲染 UI 截图（不启动 IDE）：`.workbuddy/tools/UiPreview.java`，classpath 用 gradle 缓存里的 `ideaIC-2023.3/lib/*`，必须加 `--add-exports=java.desktop/sun.font=ALL-UNNAMED` 并在最前面 `JBUIScale.setSystemScaleFactor(1f)`。产出图已替换 `static/main.png`（README 效果图）。
- `buildPlugin` 通过，产物 `build/distributions/thief-book-idea-0.1.7.zip`。

### 残余风险 / 没做的事
- 插件 id、vendor、仓库地址、持久化文件名（`thief-book.xml`）仍是旧的 —— 彻底伪装需要改插件身份，会破坏市场更新链路，未动。
- 暗色主题没有实测（离线渲染切 DarculaLaf 会卡死），靠 JBColor 配对保证，后续有机会在真 IDE 里核对一遍。
- 未跑 `runIde` 沙箱实测真实 IDE 内的交互（滚动条、epub 图片、TTS 右键菜单）。

## 追加：左侧目录可收起（v0.1.8）

需求：用户反馈左侧"历史记录"（epub 目录）一旦出现就收不掉，要求能收起侧栏；并明确**不要用底部发送键**当开关。

### 做了什么
- `AssistantIcons.sidebar(size, color, expanded)`：新图标，展开态左列填实、收起态只留一条描边。
- `MainUi`：顶部栏品牌名右侧新增 `tocToggleButton`（`headerButton(...)` 24x22 GlyphButton），伪装成 IDE 的"收起侧边栏"图标，**仅 epub 有目录时可见**；`toggleToc()` 切换折叠并写入配置，`updateTocPanel()` 统一决定面板/按钮可见性 + 图标 + tooltip。发送键（绿色 ↑）保持"下一页"语义，未动。
- `PersistentState`：新增 `tocCollapsed`（"1"/"0"，默认 "0"），进 `getState`/`loadState`。
- 版本号升 0.1.8：`build.gradle` 的 `version` 与 `plugin.xml` 的 `<version>` + change-notes 两处同步，README 加 V0.1.8 节。
- `.workbuddy/tools/UiPreview.java` 改造：一次渲染两张——`preview.png`（侧栏展开）/ `preview-collapsed.png`（收起），并模拟左侧"历史记录"列表，便于校对顶部栏按钮。

### 关键约束（别踩）
- 正文宽度自适应靠 `AssistantPageView` 的 `componentResized → applyContentWidth()`，收起侧栏后自动重排，**不要在 MainUi 里手工改段落宽度**。
- 15px 下"填实 vs 描边"差异不大，靠 tooltip（收起/展开历史记录）辅助识别。
- 预览图已替换 `static/main.png`，并新增 `static/main-collapsed.png`（README 展示用）。

## 追加：代码卡片分布优化 + 卡片头部重叠修复（v0.1.9）

需求：用户反馈"容易有很长的文字占一整页而没有代码块"，要求优化卡片位置与数量，尽量每页都有，且不限于开头结尾。

### 根因
旧算法按**段落序号**均分：`step = max(4, ceil(n/3))`，且 `MAX_EXTRA_CARDS = 2`。段落长短差异极大时（长段占满一屏、短段只有一行），会出现连续好几屏全是正文；一页 8 段（约 600 字）时只插 1 张额外卡，且挤在页面中上部。

### 改了什么（`AssistantPageView`）
- 卡片分布改为**按累计字数**：`CHARS_PER_CARD = 250`（约一屏正文的字数），`MAX_EXTRA_CARDS = 7`（加顶部那张正好用满 `DisguiseContent` 的 8 个片段，避免同页重复）。
- 插卡阈值 = `totalChars * (placed + 1) / (extraCards + 1)`，越过后在段落后插卡，页内均匀铺开。
- 兜底：整页只有一个落脚点（段落极少）时，在结尾话术前补一张。
- 顺带修掉一个既有缺陷：卡片头部 BorderLayout 在窄宽度下**文件名与右上角工具栏直接重叠**（左侧目录展开时正文区仅 ~250px）。新增 `FileNameLabel.fitTo()` 在卡片 `doLayout()` 里按可用宽度收窄文件名（优先丢目录前缀保留文件名本身，再按需省略）。

### 验证方式（新增，可复用）
`UiPreview` 现在输出三张图 + 一份**定量分布统计**：
- `preview.png`（常规页，侧栏展开）/ `preview-collapsed.png`（侧栏收起）/ `preview-long.png`（长页样本约 1100 字，画布高 2200px）。
- `reportDistribution(page)` 遍历 `pageView` 中带 `thief.cardIndex` 的组件，打印每张卡的 y 像素与百分比 —— 比肉眼看缩略图靠谱得多。
- 实测：常规页（700 字）高 1731px、3 张卡在 3% / 39% / 73%；长页（1100 字）3014px、5 张卡在 2% / 23% / 42% / 62% / 82%。卡片间隔约 600px，而视口 400~500px → 每屏都能看到代码块。

### 留意
- 单段超长（一屏都是同一段）时段落内部插不进卡片，只能靠兜底那张；未做段落切分（怕破坏原文分段）。
- 卡片头部的宽度预算写在卡片 `doLayout()` 里（`JBUI.scale(26)` + 工具栏宽 + 图标宽 + 图标间距），往头部加元素必须同步改。
